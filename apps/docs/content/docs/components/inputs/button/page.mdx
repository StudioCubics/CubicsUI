## Variants

Buttons come with multiple variants, `contained` should be used when the user should focus on a particular button like confirm button in a confirmation form etc., `outlined` variant should be used when the button needs to present itself as a button but not supposed to be the main focus, rest all use cases the default button can be used
<Sandcube title="Button Variants">
    <SandcubeFile path="/App.tsx">
      ```tsx
      import { Button } from "@cubicsui/components";
      export default function App() {
        return (
          <div>
            <Button>Default</Button>
            <Button variant="contained">Contained</Button>
            <Button variant="outlined">Outlined</Button>
          </div>
        );
      }

      ```
    </SandcubeFile>
</Sandcube>

## Colors

There are multiple colors for you to chose from the main default color should be used wherever possible, for brand based theming the `primary`, `secondary` and `tertiary` colors can be used. The other color that will be used in a lot of cases is the `error` color, this can be used to potray danger or a higher level of seriousness and caution, to also allow the other states there is `success` and `warn`, which are present for design systems that have different colors associated with different states.
<Sandcube title="Button Colors">
    <SandcubeFile path="/App.tsx">
      ```tsx

      export default function App() {
        return (
          <div>
            <Button>Default</Button>
            <Button color="primary">primary</Button>
            <Button color="secondary">secondary</Button>
            <Button color="tertiary">tertiary</Button>
            <Button color="error">error</Button>
            <Button color="warn">warn</Button>
            <Button color="success">success</Button>
          </div>
        );
      }

      ```

## API

### Props

Props specific to the Button component.


<section id="buttonbaseprops">


| Prop | Type | Default | Description |
|------|------|---------|-------------|
| **startIcon** | `ReactNode` | `—` | Renders an icon at the beginning of the button. |
| **align** | `"left" \| "center" \| "right"` | `"center"` | Justifies the content of the button |
| **endIcon** | `ReactNode` | `—` | Renders an icon at the end of the button. |
| **selected** | `boolean` | `—` | Marks the button as selected. |
| **variant** | `"contained" \| "outlined"` | `"text"` | Visual style variant. |
| **fullWidth** | `boolean` | `false` | Expands width to 100%. |
| **icon** | `boolean` | `false` | When button is supposed to be an icon button, make sure to pass a square icon to not mess up the button's size |
| **size** | `"xs" \| "sm" \| "md" \| "lg" \| "xl"` | `"md"` | Button size. |
| **disabled** | `boolean` | `false` | Adds disabled styles to the button. Added this to make `<Link/>` have disabled style in Next.js. |
| **color** | `"primary" \| "secondary" \| "tertiary" \| "error" \| "warn" \| "success"` | `—` | Color theme of the button. |
| **slotProps** | `ButtonSlotProps` | `—` | Slot props for customizing internal elements.  [ButtonSlotProps](docs/components/inputs/button#buttonslotprops) |
</section>
